# ContrastCraft

A standalone, no-dependency web accessibility project prepared for a 2027–2028 placement application.

## Run
Open `index.html` in a browser, or serve the repository using GitHub Pages.

## Features
- Live preview and hex colour inputs
- WCAG relative-luminance and contrast-ratio calculation
- AA normal (4.5:1), AA large (3:1), AAA normal (7:1) indicators
- Random palette, swap and local storage of up to 12 palettes
- Responsive CSS and accessible form labels

## Tests
1. White on black gives 21.00:1.
2. White on white gives 1.00:1.
3. Invalid hex input triggers an error.
4. Save a palette, reload, and verify it remains.
